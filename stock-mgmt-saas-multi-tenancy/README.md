# Stock Management SaaS Core Backend Module

This module contains the **Spring Boot 4.0.5 backend application** for the Stock Management SaaS platform.

For full architectural details, multi-tenancy design, setup instructions, and API documentation, please refer to the main repository README:

👉 **[Root README.md](../README.md)**

## Quick Start (Backend)

```bash
# Build
./mvnw clean package -DskipTests

# Run tests
./mvnw test

# Run application
./mvnw spring-boot:run
```

- **Swagger UI**: http://localhost:8080/swagger-ui.html
